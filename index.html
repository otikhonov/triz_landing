Методика курса
Методика

Теория решения изобретательских задач (ТРИЗ) — это подход, который переводит поиск идей из хаотичного в системный.

Команда сможет

Разбирать задачу на элементы, понимать, что влияет на результат, и перестанет действовать наугад.

Вместо ожидания вдохновения — предсказуемо находить сильные креативные решения и использовать уже доступные ресурсы.

Финальный результат

С ТРИЗ команда начинает решать задачи на новом уровне — через структуру, алгоритм и понятный подход к поиску решений.

Работа в малых группах

Формат позволяет держать высокий темп, разбирать кейсы глубоко и не терять вовлеченность участников.

Программа курса
Модуль 1 Анализ ключевых требований и определение успешности

Научитесь разбирать маркетинговую задачу через реальные требования аудитории, рынка и других участников системы, чтобы точнее понимать как улучшить результат.

В результате сможете:

  • Видеть, почему текущая реклама или оффер не дают нужного эффекта
  • Понимать, какие параметры действительно важны для клиента и рынка
  • Находить точки, где можно эффективнее и дешевле улучшить кампанию
  • Строить более точные офферы, креативы и маркетинговые решения
Модуль 2 Системные методы поиска решений

Освоите два инструмента генерации идей: метод фокальных объектов, метод двойной инверсии, и сможете предсказуемо находить кретивные решения.

В результате сможете:

  • Генерировать новые идеи для рекламы, офферов и механик продвижения
  • Находить неожиданные решения
  • Смотреть на задачу с новых сторон, а не крутить одни и те же гипотезы
  • Быстро создавать качественные гипотезы
Модуль 3 Метод фантаграмм

Научитесь системно собирать новые решения через комбинации элементов, а не ждать случайного инсайта.

В результате сможете:

  • Находить новые подходы даже в перегретых и однотипных нишах
  • Комбинировать разные элементы оффера, креатива, механики и коммуникации
  • Расширять поле идей для тестов и гипотез
  • Делать процесс генерации решений более управляемым внутри команды
Модуль 4 Идеальный конечный результат, ресурсы

Освоите один из ключевых инструментов ТРИЗ для поиска решений через уже существующие ресурсы системы - ИКР.

В результате сможете:

  • Формулировать, каким должен быть сильный результат без лишних действий и затрат
  • Видеть, какие ресурсы уже есть внутри проекта, команды, продукта
  • Искать решения не «с нуля», а на базе того, что уже доступно
  • Находить более сильные ходы для маркетинговых задач в условиях ограничений
Модуль 5 Практический блок по ИКР

Отдельная практическая отработка навыка поиска «бесплатных» ресурсов, которые уже есть в системе и могут быть использованы для решения маркетинговых задач.

В результате сможете:

  • Находить ресурсы, за которые уже заплачено, но которые пока не используются
  • Усиливать кампании без дополнительного бюджета
  • Видеть новые возможности в текущих процессах, контенте и каналах
  • Искать решения через переиспользование того, что у команды уже есть
